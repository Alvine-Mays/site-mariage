Recommandations

Pour les Dames

  • Robes longues ou mi-longues dans les tons or, marron, crème ou beige
  • Accessoires dorés ou en tons chauds
  • Chaussures confortables pour danser
  • Évitez le blanc (réservé à la mariée) et le noir

Pour les Messieurs

  • Costume ou tenue élégante dans les tons marron, beige ou crème
  • Chemise claire avec cravate ou nœud papillon doré
  • Chaussures en cuir marron ou beige
  • Accessoires dans les tons chauds

L'importance du Dress Code

Respecter le dress code nous tient particulièrement à cœur car il contribue à créer une atmosphère harmonieuse et élégante pour notre mariage. Vos tenues dans ces couleurs créeront un magnifique tableau visuel qui restera gravé dans nos mémoires et sur nos photos.

Merci de votre participation !
